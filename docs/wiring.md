# 接线与供电核对

核验：2026-10-19。本文件保留排查阶段与最新起转记录；最新状态为USB直连、空载短时正反转及停止已确认，持续带载能力未验证。确认范围必须区分用户口头确认、照片观察与电气测量。

## ATOMS3 Lite 实际位置

将底面标签朝向自己、USB-C 插口朝下，按官方 PinMap：左侧从上到下为 **3V3、G5、G6、G7、G8**；右侧从上到下为 **G39、G38、5V、GND**。这是底视图，不能照顶视方向反接。下方 Grove 接口是 GND/5V/G2/G1，不是 G5/G6。

[M5Stack 官方底部引脚图](https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/471/C124_PinMap_01.jpg)

M5Stack 产品页确认 ESP32-S3FN8、8MB 和 G5/G6 引出；Espressif 的 LEDC 可通过 GPIO 矩阵路由到这两个输出 GPIO。固件已编译，实际波形仍需示波器或逻辑分析仪验证。

## 已确认与未确认

用户已逐项确认最初表格全部一致：G5→AIN1、G6→AIN2、3V3→使能、GND→GND、5V→VM、AO1→电机红线、AO2→白线。但照片实物使能丝印为 **STBY**；照片中还有延长／转接线，不能用线色单独证明每个电气网络。照片里的电机引线颜色也不是最初描述的红白直连，应以端点连续性为准。

最新 20261019-150956.jpeg 已展示驱动芯片正面，但字样模糊不可辨，尚未确认 DRV8833 型号、封装、模块上拉电阻、采样电阻和散热设计。STBY 是模块网络标签，不足以推断芯片型号。需可辨识的芯片型号或匹配模块原理图；PCB 上的 V318 不能证明芯片型号。

共地为用户接线确认，尚未用万用表测连续性。模块与电机裸露焊点应绝缘、固定，电机空载测试时固定壳体，轴周围保持净空。

## DRV8833 条件性核对

以下仅适用于确认是真正 DRV8833 后：VM 工作范围 2.7–10.8V；AIN 高阈值 2V、低阈值 0.7V；nSLEEP 高阈值 2.5V、低阈值 0.5V。3.3V 输出符合输入高电平要求。nSLEEP 芯片内部约 500kΩ 下拉，不是上拉；高电平启用，唤醒需等待约 1ms。模块有没有外接上拉仍未知。若上拉连到 VM，尤其不能未经核对把它直接接到主控 3V3 电源轨。

桥输出条件：AIN1/AIN2=0/0 滑行，1/0 正转，0/1 反转，1/1 制动。软件只用单边 PWM，另一边固定低。额定连续电流与封装/散热有关，不能把所有廉价模块都视作 1.5A 连续；PW 版本的数据手册额定值更低。芯片过流保护不等于 USB 供电限流或电机堵转保护。

## 电机及 USB 电源

用户已确认购买 6V、150RPM、3mm 轴 N20。供应商通用表中 6V 系列空载 0.05A、额定负载 0.18A、堵转 0.8A。表中并无精确 150RPM 行；数据只作为风险估计依据，未实测。

估算绕组 R≈6/0.8=7.5Ω；若相同绕组温度，5V 堵转约 5/7.5=0.67A。实际还受电刷接触、驱动压降、电源及导线影响。20% PWM 不等于峰值电流只剩 20%，也不能保证低占空比能起转。USB 枚举曾显示分配 500mA，该值不能作为电源瞬态承载实测。主控还要耗电，这些估计不能用于认定USB持续供电能力；后续实际USB空载短时结果见文末。

M5Stack 页面当前名为 Lite 的原理图链接实际指向带 LCD 的 AtomS3 图纸；其中 1A PPTC 标记也不能证明实物 Lite 或整个 USB 链路可持续供应电机，本文不据此批准带电运行。

## 拟用独立供电方案（待用户确认、未实施）

| 从 | 到 | 说明 |
|---|---|---|
| ATOMS3 G5 | 驱动 AIN1 | 3.3V PWM |
| ATOMS3 G6 | 驱动 AIN2 | 3.3V PWM |
| ATOMS3 3V3 | 经核实的 nSLEEP / STBY | 先确认芯片及模块电路 |
| ATOMS3 GND | 驱动 GND | 与电机电源负极共地 |
| 独立稳压限流电源 +5V（初测） | 驱动 VM | 电机独立供电 |
| 独立电源负极 | 驱动 GND | 电机电流直接回电源，不经过主控细地线 |
| 驱动 AO1/AO2 | 电机两端 | 正反方向以实物运行确认 |
| ATOMS3 5V | **不连接 VM** | 避免回灌及 USB 承担电机电流 |

电源建议具备足够瞬态容量（至少约 1A 供电能力）及可调限流；这不表示应允许电机长时间堵转。初测限流值需在确认驱动封装、模块能力和实物电机规格后确定。切断开关放在电机电源正极、靠近操作者。VM 旁退耦和储能电容按 TI 与模块设计核对，至少需满足芯片推荐的 10µF 陶瓷旁路，额外电容根据线长和回生测量决定。

## 单独刷写主控的最小步骤

全部断电 → 移除并绝缘 5V→VM 导线，确保 VM 不接任何其他电源 → 保持电机断电，只插主控 USB → 再核实枚举和芯片身份。此方案允许固件准备，不等于批准恢复电机电源。第一次带电机测试须单独确认。

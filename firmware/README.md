# 固件

版本 conveyor-1.0.0，协议版本 1。使用 PlatformIO 构建，配置见 platformio.ini。

`include/MotorCore.h` 为与硬件解耦的安全状态机；`src/main.cpp` 负责 JSON 校验、USB、LEDC、NVS、看门狗和按钮。原生 C++ 测试直接编译同一份 MotorCore.h。

引脚：GPIO5→AIN1，GPIO6→AIN2，GPIO41 为本体按钮。LEDC 低速模式，两个通道共用定时器 0，10bit，默认 20kHz。0/0 为滑行停止；正转 PWM/0，反转 0/PWM；输出更新前先归零两个通道。本固件不使用 1/1 制动组合；DRV8833 的 1/1 本身是手册允许的制动模式，不能误称为芯片内部直通。

方向切换非阻塞，换向延迟期间仍可处理急停。即便先 STOP 再立即反转，仍保留前一方向和停机时间，不能绕过等待。没有测速，300ms 不保证所有负载都已静止，应在实机测试后调整。

每次上电均停止、未使能；只保存参数。握手会话重建也会停止并撤销使能；心跳不能自动恢复运动。USB bool 状态只提供尽力而为的即刻检测，网页关闭依靠同一 MCU 心跳租期兜底；桥接服务不代发心跳。超时至少 500ms，不可设为无限。

任务看门狗配置 1000ms、复位；USB TX 非阻塞，只有空间足够才发送完整帧，避免因主机不读取而卡住安全循环。慢速主机可能漏 ACK，网页会断开并停止心跳。固件不是功能安全认证系统；硬件断电措施必需。

NVS 命名空间 conveyor-v1，单 blob 存储有版本的 Settings。读取长度或范围无效时恢复安全默认值。NVS 失败显示 nvsReady=false，保存返回 E_NVS。掉电恢复待真实设备验证。

未来可在另行核对引脚后使用 G7/G8 接编码器 A/B，新增 PCNT 测速模块、测量质量与 rpm 字段，再设计闭环；当前这些引脚没有被占用或宣称支持测速。

# Public verification evidence

Selected UI screenshots and sanitized observations are included. Device MAC/USB serial and host paths are removed from text records. Only the selected marked-direction command excerpt is published. Full raw serial/flash logs, full flash/NVS backups, native test executables and private runtime data are deliberately excluded.

`public-release-checks.json` records the public-copy build and software tests. Physical results refer to the earlier board firmware built from the same main.cpp/MotorCore.h source, not an additional flash or a new hardware test of the public images.
